# проверка и поиск ipv6-адресов

лабораторная работа по прикладному программированию. консольная программа
проверяет правильность записи ipv6-адреса и ищет адреса в текстовом файле
с помощью регулярного выражения.

## запуск

нужен python 3.10 или новее. дополнительные библиотеки устанавливать не нужно.
в pycharm запустить `main.py` или в терминале из папки проекта:

```bash
python3 main.py
```

в меню выбрать действие:

1. ввести ipv6-адрес и проверить его;
2. указать путь к текстовому файлу и найти в нём ipv6-адреса;
0. выйти из программы.

для примера поиска можно указать файл `example.txt`. файл должен быть в
кодировке utf-8. если файл не найден или не читается, программа покажет ошибку.

программа проверяет полный и сокращённый вид ipv6, а также адреса со встроенным
ipv4. при поиске найденные адреса выводятся в том порядке, в котором они
встречаются в тексте.

## сохранение результата

после проверки или поиска результат записывается в `result.json` в папке,
из которой запущена программа. при следующем действии файл перезаписывается.
файл с результатом не добавляется в git.

## запуск тестов

из папки проекта выполнить:

```bash
python3 -m unittest -v
```

тесты проверяют правильные и неправильные адреса, сокращённую запись ipv6,
адреса со встроенным ipv4 и поиск в тексте.

## структура проекта

| файл | назначение |
| --- | --- |
| `main.py` | меню, ввод и вывод, сохранение результата в json |
| `ipv6.py` | регулярное выражение, проверка и поиск адресов |
| `test_ipv6.py` | unit-тесты |
| `example.txt` | пример текста для поиска |
| `.gitignore` | файлы, которые не добавляются в git |
